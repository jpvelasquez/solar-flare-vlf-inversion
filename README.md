# Open Research package: solar-flare effects reconstructed from VLF time series

This repository bundles the data, code, notebooks, inversion outputs, and provenance records used for the NAA--PLO solar-flare reconstruction study centered on the 25 March 2008 M1.7 flare.

## Contents

- `data/savnet/`: SAVNET raw data for 25 March 2008 only.
- `data/goes/`: GOES-10 XRS 1-min March 2008 product used for the solar X-ray context.
- `data/background_separation/`: ASLS, Whittaker, and PolyF3 separated backgrounds used as inversion targets.
- `data/background_inversion/`: BBO-1/BBO-2 background inversion outputs for the three background families.
- `data/perturbation_inversion/`: BBO-1/BBO-2 flare-perturbation inversion outputs for ASLS, Whittaker, and PolyF3.
- `data/synthetic/`: archived outputs of the two canonical synthetic inversions.
- `data/evaluation_5min/`: 5-min forward reevaluations used for final comparisons/figures.
- `code/julia/`: Julia inversion code and local helper files.
- `code/slurm/`: Slurm launcher snapshots associated with the Engaging runs. Some launcher files were edited between runs; canonical run identity is established from the job logs and HDF5 outputs, not solely from the present launcher text.
- `notebooks/`: curated local notebooks for preprocessing, synthetic validation, real-data analysis, and final figures.
- `supporting_information/ground_sensitivity/`: data, code, and notebooks for the lower-boundary/ground sensitivity tests.
- `provenance/job_logs/`: stdout/stderr from canonical Engaging jobs.
- `metadata/`: file manifest, SHA-256 checksums, run-to-script/output mapping, and provenance caveats.

## Julia environment

The top-level `Project.toml` and `Manifest.toml` preserve the supplied Julia environment. The manifest records Julia 1.11.6. A separate historical environment associated with `mytools` is preserved under `code/julia/mytools/`.

Typical setup:

```bash
julia --project=. -e 'using Pkg; Pkg.instantiate()'
```

Several Julia scripts call Python through PyCall (`numpy`, `scipy`, and `chaosmagpy`).

## Python environment

`environment-python-requirements-minimal-unpinned.txt` lists the Python packages inferred from the curated notebooks and Slurm preflight checks. The exact historical Python package versions were not preserved in the supplied materials; this is therefore a dependency list, not a bit-for-bit Python environment lock file.

## Core data flow

### Observational case

1. `data/savnet/PLO-20080325.fits` contains the one-day Punta Lobos SAVNET record.
2. The three background families used in the inversions are archived in `data/background_separation/`.
3. Their physical Wait--Spies background inversions are archived in `data/background_inversion/`.
4. The corresponding flare inversions are archived in `data/perturbation_inversion/`.
5. The 5-min forward reevaluations used in final comparisons are in `data/evaluation_5min/`.

The ASLS preprocessing lineage is represented by `notebooks/preprocessing/PyBaselines-data-Copy1.ipynb`. The notebook was edited after the canonical `datos_asls_full-v3.h5` had been produced (the later notebook writes `v4`), so the archived `v3` HDF5 plus the inversion job outputs/logs are the authoritative canonical artifacts for the published chain. See `metadata/PROVENANCE_CAVEATS.md`.

### Synthetic validation

The synthetic background and perturbation inversion scripts are in `code/julia/canonical_main/`. Their canonical outputs are:

- job 12260814: `data/synthetic/new-normalized-synthetic-inversion_results_12260814.h5`
- job 12343185: `data/synthetic/new-normalized-perturbation-synthetic-inversion_results_12343185.h5`

Input products such as the FIRI reference field, synthetic perturbation target, and synthetic background/perturbation separation are generated by the curated notebooks under `notebooks/synthetic/` rather than duplicated as intermediate files.

### Ground sensitivity / Supporting Information

The Supporting Information bundle preserves the 13-ground reference output, controlled forward diagnostic, and ocean/5+5 inversion outputs. Curated notebooks are included for generating and visualizing the ground references and comparing the 5+5 sensitivity case.

## Integrity

`metadata/SHA256SUMS.txt` contains SHA-256 hashes for every file in the package except the checksum file itself. `metadata/MANIFEST.tsv` lists file paths, sizes, hashes, and top-level categories.

## Provenance caveats

See `metadata/PROVENANCE_CAVEATS.md`. Two historical snapshots were not preserved exactly:

1. the ASLS preprocessing notebook state that originally wrote `datos_asls_full-v3.h5`; and
2. the exact pre-run snapshot of the ASLS background restart script for job 13341497.

The canonical numerical outputs for both chains are included. For job 13341497, a clearly labeled reconstructed script was created from the later supplied script, its inline history, and the canonical job log; the later modified source is preserved under `provenance/post_run_snapshots/`.
